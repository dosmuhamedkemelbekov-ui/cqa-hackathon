Настройки чек-листа

«Применить» сохраняет новую версию чек-листа на сервере и переоценивает диалоги набора. ИИ заново оценивает только новые и изменённые критерии; при смене одних весов баллы пересчитываются без вызова модели, а вердикты супервизора по неизменённым критериям сохраняются.

Σ весов: 100.00 / 100
Перераспределение при N/A: w′ᵢ = wᵢ / Σwактивных × 100. Критерий-флаг «Грубые ошибки» не имеет веса и не участвует в сумме. Для шкальных критериев доля = ступень / максимум шкалы (например, критерий 06: (ступень / 10) × 15). Итог округляется до двух знаков.

Обучение на апелляциях · прецедентов: 0

Каждое изменение оценки супервизором становится прецедентом: при следующих оценках ИИ получает его как пример трактовки правила по этому критерию. В оценку того же диалога прецедент не подмешивается — без утечки ответа.
